# Glint

Whatasiger 博客的界面主题，基于 [Hingle](https://github.com/Dreamer-Paul/Hingle)（作者 Dreamer-Paul）大幅改写而来：毛玻璃卡片、主题色、日夜模式、阅读页目录、沉浸模式、首页水波纹、CARRiER WAVE. 等都是在此之上的定制。

## 使用

- 放在 Hexo 目录的 `themes/glint`，站点 `_config.yml` 中 `theme: glint`
- 主题配置见本目录的 `_config.yml`（可参考 `_config.example.yml`；原版配置项说明见 [Hingle 主题文档](https://docs.paul.ren/hingle)）
- 样式与脚本：`source/static/glint.css`、`source/static/glint.js`
