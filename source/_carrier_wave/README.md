# CARRiER WAVE. 写作参考

> 被留下的成为信号，被遗漏的进入 limbo。

本文件只供写作时参考，不会被生成到网站上（Hexo 忽略 `_` 开头的目录，`scripts/carrier-wave.js` 也只读取曲目表里的 slug）。

---

## 一、总述

《CARRiER WAVE.》是由十八篇彼此独立、却暗中相连的小说组成的短篇辑。全集借用音乐专辑的结构：每篇像一首曲目，有各自的情节、人物和情绪，同时又遵循同一套藏在文本深处的叙事规律。

整部作品围绕两个概念展开：**carrier wave（载波）**与 **limbo**。

**载波**本身不携带任何信息，但信息要靠它才能传出去。在这部作品里，「创作」本身，以及游荡在部分篇目中的第一人称「我」，扮演的就是载波：把十八个世界里的人物、记忆、情绪和故事，传给读者。

但任何叙述都无法完整保存一个世界。每一次选择、书写和记忆，都会同时造成遗漏，**limbo** 就存在于这些遗漏之中。它不是某个具体的人物、神秘实体或幕后操纵者，更接近叙事的负空间：那些没有真正进入文本、没有被记住、没有被看见，甚至无法被完整描述的人、事件、记忆、规则和信息。它们却真实地参与了因果，改变了人物。比如：

- 一个角色忘记了改变自己一生的童年好友，却还留着对方送的物件；
- 一个无法确认是否存在的信号，可能已经促成了一段真实的旅程；
- 一个被遗忘的原因，仍然留下了结果。

于是，「存在」和「被叙述」之间出现了一道缝隙，limbo 就住在那里。

随着十八篇故事展开，这种缺失不会被直接解释，只会悄悄出现在**记忆的断层、来历不明的物件、无法确认的信号、反常的叙述权限、意义不明的空白**里。直到最后的《limbo.》和《CARRiER WAVE.》，读者才意识到：这些看似偶然的空缺，始终属于同一个结构。

整部作品最终讨论的不是一个需要破解的谜题，而是「传达」本身的局限。我们通过语言、记忆和创作把自己传递给他人，却永远只能传递其中一部分。被留下的成为信号，被遗漏的进入 limbo；生命、成长，以及人与人之间的联系，就发生在这两者之间。

「我」和 limbo，可以理解为游荡在这十八篇之间的两个角色。

## 二、结构

### 篇目类型

| 类型 | 篇目 | 视角 | 目标篇幅 |
|---|---|---|---|
| intro / outro | SIN.、CARRiER WAVE.（同名曲收尾） | 第一人称「我」 | — |
| 随笔篇 | Anecdoche.、Sonder.、Énouement. | 第一人称「我」，读来像作者本人的随笔 | 各约 1000 字 |
| 主打 | PATHOS. | 第三人称限知 | 约 10000 字，最长的单篇 |
| 中篇（拆分穿插） | maMihlApinaTapEi. 1st–4th、AIRS. Ⅰ–Ⅲ | 第三人称限知 | — |
| 其余单篇 | Eden.、Eric.、Remy.、Mora.、limbo. | 第三人称限知 | 多为 2000 字左右 |
| 隐藏篇 | i.（只能从标题里的 i 进入） | 作者现身 | — |

**两个中篇的编排**：maMihlApinaTapEi. 分四段、AIRS. 分三段，在曲目中交替出现（03 / 07 / 11 / 14 与 06 / 09 / 16），像专辑里反复回来的主题。

**标题彩蛋**：
- 「maMihlApinaTapEi.」的大写字母连起来是 **MATE**（标题词源是雅甘语：两人对望，都盼着对方先开口，却谁也没有开口）；
- 「CARRiER WAVE.」里小写的 **i** 通往隐藏篇《i.》，末尾的句点通往《.》（dot.md，伪彩蛋）；
- Anecdoche、Sonder、Énouement 都出自《The Dictionary of Obscure Sorrows》。

### 网页上的呈现（已实现）

- 每篇有自己的载波颜色。limbo. 的载波是**黑色**，读的时候只有进度点照亮前后一小段；最后一首 CARRiER WAVE. 的载波被**拉直**，不复存在。
- limbo. 在目录中与前面各篇隔开。
- 正文文件不存在或为空的篇目，在目录中显示为「未接收」。

## 四、已经埋下的 limbo 痕迹

下面按总述里五种显现方式，整理目前文本中已经出现、可以继续利用的线索。这些只是对现有文字的观察，不代表既定设定。

**记忆的断层**
- PATHOS.：Pascal 坚持弹电吉他，是为了把音乐送给一个发小，如今却只剩模糊的记忆，想不起名字和长相。
- Eric.：木筏上似乎做了一场梦，梦的内容已经忘记了。
- limbo.：「我们」彻底忘了 limbo 是什么，以及它存在的意义。

**来历不明的物件**
- PATHOS.：琴头的挂件「摇滚乐永不停歇」，「应该是很久之前有人送我的」。这和总述里"忘记了童年好友，却还留着对方送的物件"的例子直接对应。
- Eden.：那只体格偏大、毛色黯淡、总趴在角落的羊，最后主动跟着 Eden 上路。

**无法确认的信号**
- maMihlApinaTapEi. 1st：Skye 看到的飞碟亮点，最终没有找到，却促成了那一趟上山的旅程。
- maMihlApinaTapEi. 2nd：「从天线向宇宙发送信号开始，有什么东西就逐渐改变了」。
- PATHOS.：Ansel 的钢琴声只有 Ansel 自己听得见；Theon 拨出的电话，铃声明明炸响了，却又像没有声音。

**反常的叙述权限**
- Mora.：第一句就宣告「明天早上，Mora 会死亡」，叙述者知道角色不知道的事；回家路上那辆差点撞上的车。
- Anecdoche.：这一篇里出现了其他篇目的原句，好像这个「我」能听到所有频道。
- i.：作者藏在载波里。

**意义不明的空白**
- AIRS. Ⅰ：笔记本里署名被涂黑的「K. —— ██」；正文中间留下的一段空白。
- maMihlApinaTapEi. 4th：「带自己出去玩的、最爱的朋友」，为什么还需要"再一次"见面，没有说明。

## 五、各篇共用的意象

目前各篇之间互相呼应的元素，写后续篇目时可以继续沿用，也可以有意识地控制出现的频率。

- **路口与红绿灯**：Eden.（守着绿灯的契约）、Mora.（每天经过的十字路口、没有斑马线的横穿）
- **山坡**：「一座绿草茵茵的山坡，只在坡顶有一棵大树」出现在 Eric. 和 Anecdoche.；maMihlApinaTapEi. 1st 的山顶日出；Anecdoche. 里的「半山腰上的人，他还好吗」
- **猫**：Eden. 的 Sunny（晴天）、Eric. 的拉米、Mora. 家里的两只小猫
- **电波与信号**：PATHOS. 的广播站、Eric. 的「天文台的电波频段」、maMihlApinaTapEi. 2nd 的天线、Anecdoche. 的「交错的电波」
- **复现的句子**：
  - 「人生在最后的时刻如果只是抱着这样的问题死去，或许有些太悲哀了吧」（PATHOS.、Anecdoche.）
  - 「一缕细风，树叶轻摇」（maMihlApinaTapEi. 1st、Anecdoche.）
  - 「噔噔噔」（maMihlApinaTapEi. 1st 的敲窗、Anecdoche.）
  - 「黄油面包」（limbo. 里的暗号、Anecdoche.）
  - 「我们通过语言、记忆与创作将自己传递给他人，却永远只能传递其中的一部分」（Anecdoche.，也是整部作品的主题句）
- **校园与考试**：周测、期末、答题卡、数学卷子，贯穿 PATHOS.、AIRS.、Mora.、Anecdoche.

**写法上的统一**：全集几乎不使用"他/她"，人物始终直呼其名。
